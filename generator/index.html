조건을 설정하는 무료 로또생성기

1부터 45까지의 숫자 중 중복 없는 6개를 생성합니다. 로그인 없이 이용하며, 생성한 번호를 서버에 저장하지 않습니다. 고정·제외 번호와 비율·합계 조건을 조합해 원하는 형태의 로또 번호를 만들 수 있습니다.

로또 번호 생성 방법

  1. 포함할 숫자는 한 번 눌러 고정하고, 제외할 숫자는 두 번 누릅니다.
  2. 홀짝과 고저의 최소·최대 비율을 설정합니다. 최소 2:4부터 최대 4:2까지 선택하면 2:4, 3:3, 4:2를 모두 허용합니다.
  3. 번호 6개의 합계 최소·최대, 연속 번호와 구간별 최대 개수를 선택합니다.
  4. 게임 수를 1·5·10 중 선택하고 ‘번호 만들기’를 누릅니다. 결과마다 실제 비율과 합계를 확인하고 번호를 복사할 수 있습니다.

고저 비율과 홀짝 비율은 어떻게 계산하나요?

고번호는 24~45, 저번호는 1~23입니다. 고 4:저 2는 고번호 4개와 저번호 2개를 뜻합니다. 홀짝 비율은 생성 번호의 홀수와 짝수 개수이며, 범위의 양 끝 비율도 포함합니다. 최소와 최대를 같게 설정하면 하나의 비율만 허용합니다.

합계 110~170은 무엇을 뜻하나요?

생성한 6개 숫자를 더한 값이 110 이상, 170 이하인 조합입니다. 원클릭 조건 버튼을 누르면 홀짝·고저 각각 2:4~4:2와 합계 110~170이 설정됩니다. 이후 ‘번호 만들기’를 눌러 새 조건으로 생성하세요.

과거 1등·2등 번호도 확인할 수 있나요?

생성한 번호를 수집된 역대 추첨 결과와 비교합니다. 당첨번호 6개가 일치하면 1등 번호 일치, 당첨번호 5개와 보너스 번호가 일치하면 2등 번호 일치로 표시합니다. 과거 번호 일치는 실제 복권 당첨을 의미하지 않습니다.

조건을 설정하면 당첨 확률이 올라가나요?

아니요. 공정한 로또 6/45 추첨에서는 한 조합의 1등 확률이 1/8,145,060입니다. 비율·합계·출현 빈도는 생성할 조합을 고르는 조건이며 다음 추첨을 예측하거나 당첨 확률을 높이지 않습니다. 고정·제외 번호가 다른 조건과 충돌하면 조건을 바꿔야 합니다.
